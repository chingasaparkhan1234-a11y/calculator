# Simple Interest Calculator

A simple application designed to calculate the interest accrued on a principal amount over a specific period of time at a fixed interest rate.

## Formula
The application uses the standard simple interest formula:
**A = P * (1 + r * t)**

Where:
* **A** = Total accrued amount (Principal + Interest)
* **P** = Principal amount (Initial investment or loan balance)
* **r** = Annual interest rate (in decimal format, e.g., 5% = 0.05)
* **t** = Time period (in years)

## Features
* Calculates total accrued amount instantly.
* Displays a clear breakdown of the total interest earned or charged.
* User-friendly interface with data validation.

## How to Use
1. Enter the **Principal Amount**.
2. Input the **Annual Interest Rate** (as a percentage).
3. Specify the **Time Period** in years.
4. Click **Calculate** to view the results.
